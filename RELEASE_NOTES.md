# macOS Mic Priority 1.0.0

The first public release of macOS Mic Priority, a native menu-bar utility that prevents newly connected headphones and other audio devices from taking over the default microphone.

## Highlights

- Arrange connected microphones into an ordered priority list.
- Automatically use the highest-priority device that is available.
- Fall back when a microphone disconnects and restore it when it reconnects.
- Pause protection or manually select a device from the menu-bar popover.
- Start automatically at login through the macOS Login Items system.
- No audio recording, microphone permission, analytics, or network access.

## Compatibility

- macOS 13 Ventura or newer
- Universal binary for Apple Silicon and Intel Macs

# Changelog

All notable changes to macOS Mic Priority are documented here.

## [1.0.0] - 2026-08-26

### Added

- Native macOS menu-bar application
- Persistent ordered microphone priority list
- Core Audio listeners for device and default-input changes
- Automatic fallback and restoration behavior
- Launch at Login integration
- Local-only preferences and privacy manifest
- Reproducible build, verification, installation, and release scripts

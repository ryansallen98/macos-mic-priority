# Contributing

Thanks for helping improve macOS Mic Priority.

1. Open an issue describing the behavior or proposed change.
2. Keep changes focused and use public macOS APIs.
3. Do not add analytics, network access, audio capture, private frameworks, secrets, or third-party binary dependencies.
4. Run `./scripts/check.sh` before submitting a pull request.
5. Update `CHANGELOG.md` for user-visible changes.
